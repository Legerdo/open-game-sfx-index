## ✨ What is this?

**2,186 CC0 game sound effects** (OGG/WAV/FLAC, ~95 MiB total) from
[Kenney.nl](https://kenney.nl/assets/category:Audio) and CC0-verified
[OpenGameArt.org](https://opengameart.org) packs, organized so that
**humans can listen in one click** and **AI agents can search without downloading everything**.

| I am… | Do this |
|-------|---------|
| 🧑 Human | Open [🎧 **previews/README.md**](previews/README.md) → pick a pack → press ▶ on any sound |
| 🤖 AI agent | Use [MCP/WebMCP search tools](docs/MCP.md) or fetch [`index.json`](https://raw.githubusercontent.com/Legerdo/open-game-sfx-index/main/index.json) → download **one** chosen file |

> ⚖️ **100% copyright-safe:** all audio is **Creative Commons CC0 1.0** (public domain).
> Independent community index — not affiliated with Kenney. Proof in [ATTRIBUTION.md](ATTRIBUTION.md).

## 🤖 For AI agents

**Tool-based access:** This fork exposes the following tools, backed by the same
catalog and keyword scorer as the website:

| Tool | Purpose |
|------|---------|
| `search_sfx` | Search by Korean/English/Arabic keywords and common synonyms; filter by category, pack, format or duration; retry partial matching with `match_mode: "any"` |
| `get_sfx` | Get exact audio metadata and download URLs by ID |
| `list_sfx_categories` | Discover available categories and packs |
| `preview_sfx` | Play a sound on the website (WebMCP browser agents only) |

Open the [live website](https://legerdo.github.io/open-game-sfx-index/) in a WebMCP-enabled browser,
or launch the local stdio MCP server for your coding agent:

```sh
npm ci
node mcp/server.mjs
```

See [docs/MCP.md](docs/MCP.md) for Windows MCP client configuration,
supported browsers and examples. The MCP server reads only the local `index.json`;
it does not download or transmit the full audio collection.

**Direct catalog access** also remains available without MCP:

```python
import json, urllib.request
URL = "https://raw.githubusercontent.com/Legerdo/open-game-sfx-index/main/index.json"
idx = json.load(urllib.request.urlopen(URL))          # ~3.9 MB catalog, not the full audio collection
hits = [s for s in idx["sounds"]                      # filter locally
        if "click" in s["tags"] and s["category"] == "ui"]
print(hits[0]["download_url_ogg"])                    # download ONE file only
```

Or locally: `python scripts/search.py --q "button click" --limit 5`
(Arabic works too: `--q "زر"`)

📖 Full guide: [docs/AGENT_GUIDE.md](docs/AGENT_GUIDE.md)

Each entry carries: `id, title, pack, category, tags, use_cases, mood,`
bilingual `keywords_en/ar, duration_sec, size, sha256, download URLs, license, source`.
Newly imported packs also provide `author` and `source_archive`.

## ❓ FAQ

**Is this the complete Kenney audio collection?**
Yes — all **10 packs** in the [Audio category](https://kenney.nl/assets/category:Audio),
verified file-by-file against the upstream ZIPs (753 OGG shipped − 9 preview tracks = **744**).
On top: **18 CC0 packs from OpenGameArt** (1,442 sounds). Total **2,186**.
The latest 10 packs contribute 735 distinct sounds from rubberduck. For each pack,
the importer verified the original CC0 page, checked the ZIP archive, decoded
every sound, and checked for duplicate file and decoded audio content against
the existing library. See [the import audit](docs/CC0_IMPORT_AUDIT.json) and
[source manifest](scripts/cc0_oga_packs.json).

**Why OGG + WAV + FLAC?**
Kenney ships OGG; OGA authors ship WAV/FLAC (one AIFF pack converted losslessly to WAV).
Every format plays on GitHub file pages and in game engines.

**Why no Sonniss / Freesound?**
Sonniss forbids redistribution as a sound library (and any AI use) — legally excluded,
see [ATTRIBUTION.md](ATTRIBUTION.md). Freesound needs your API key — give it and we'll import.

**Can I use these commercially?**
Yes. CC0 = public domain: commercial use, modification and redistribution allowed,
no permission or attribution required (credit appreciated).
